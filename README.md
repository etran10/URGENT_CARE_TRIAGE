# URGENT_CARE_TRIAGE
A patient waiting triage system for an UrgentCare based on pain level

## Features

- Patient self check-in kiosk
- Priority queue based on pain level
- Waiting list
- Patient status updates
- Automatic provider assignment
- Staff-only dashboard
- Provider availability tracking
- Real-time queue management
- Streamlit GUI

## How the Triage System Works

Patients are prioritized using a priority queue.

Higher pain levels are seen first.
If two patients have the same pain level, the patient who checked in earlier is prioritized.

Providers are automatically assigned to the next patient when available.
